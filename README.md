# Bank Widget Backend Utilities

Утилиты для обработки данных банковских операций клиента. Проект содержит функции для маскирования номеров карт и счетов, а также для фильтрации и сортировки операций.

## Описание проекта

Этот проект является частью системы для отображения информации о банковских операциях клиента. Включает:

- **Маскирование данных**: Безопасное отображение номеров карт и счетов, скрывая конфиденциальную информацию
- **Форматирование дат**: Преобразование дат из ISO-формата в удобный формат DD.MM.YYYY
- **Фильтрация операций**: Выборка операций по статусу
- **Сортировка операций**: Сортировка операций по дате

## Требования

- Python 3.8+
- Зависимости указаны в `pyproject.toml`

## Использование

### Маскирование номеров карт и счетов

```python
from src import mask_account_card

# Маскирование карты
result = mask_account_card("Visa Platinum 7000792289606361")
# Результат: "Visa Platinum 7000 79** **** 6361"

# Маскирование счета (на английском)
result = mask_account_card("Account 73654108430135874305")
# Результат: "Account **4305"

# Маскирование счета (на русском)
result = mask_account_card("Счет 73654108430135874305")
# Результат: "Счет **4305"
```

### Форматирование дат

```python
from src import get_date

# Преобразование даты
date = get_date("2024-03-11T02:26:18.671407")
# Результат: "11.03.2024"
```

### Фильтрация операций

```python
from src import filter_by_state

operations = [
    {"id": 1, "state": "EXECUTED", "amount": 1000},
    {"id": 2, "state": "CANCELLED", "amount": 2000},
    {"id": 3, "state": "EXECUTED", "amount": 3000},
]

# Фильтрация по состоянию (по умолчанию "EXECUTED")
executed = filter_by_state(operations)
# Результат: [{"id": 1, "state": "EXECUTED", "amount": 1000}, {"id": 3, "state": "EXECUTED", "amount": 3000}]

# Фильтрация по другому состоянию
cancelled = filter_by_state(operations, "CANCELLED")
# Результат: [{"id": 2, "state": "CANCELLED", "amount": 2000}]
```

### Сортировка операций

```python
from src import sort_by_date

operations = [
    {"id": 1, "date": "2024-01-01", "amount": 1000},
    {"id": 2, "date": "2024-01-03", "amount": 2000},
    {"id": 3, "date": "2024-01-02", "amount": 3000},
]

# Сортировка по дате (по умолчанию по убыванию)
sorted_desc = sort_by_date(operations)
# Результат: операции отсортированы от новейших к старейшим

# Сортировка по дате в порядке возрастания
sorted_asc = sort_by_date(operations, reverse=False)
# Результат: операции отсортированы от старейших к новейшим
```

## Разработка

### Инструменты для проверки качества кода

Проект использует следующие инструменты:

- **flake8**: Проверка соответствия PEP 8
- **mypy**: Проверка типов Python
- **isort**: Форматирование импортов

Для проверки кода:

```bash
# Проверка flake8
flake8 src/

# Проверка типов mypy
mypy src/

# Форматирование импортов
isort src/
```
