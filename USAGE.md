# Инструкция по использованию программы обработки банковских операций

## Реализованные функции

### 1. `process_bank_search(data: list[dict], search: str) -> list[dict]`
**Расположение:** `src/processing.py`

Функция принимает список словарей с данными о банковских операциях и строку поиска. Возвращает список словарей, у которых в поле `description` есть совпадение с поисковой строкой.

Использует регулярные выражения (`re.search()`) для поиска с игнорированием регистра.

**Пример использования:**
```python
from src.processing import process_bank_search

operations = [
    {"description": "Открытие вклада", "amount": 40542},
    {"description": "Перевод с карты", "amount": 130},
]

# Поиск операций содержащих "вклада"
result = process_bank_search(operations, "вклада")
# Результат: [{'description': 'Открытие вклада', 'amount': 40542}]
```

### 2. `process_bank_operations(data: list[dict], categories: list) -> dict`
**Расположение:** `src/processing.py`

Функция принимает список словарей с данными о банковских операциях и список категорий. Возвращает словарь, где ключи — названия категорий, а значения — количество операций в каждой категории.

Категории определяются на основе содержимого поля `description`.

**Пример использования:**
```python
from src.processing import process_bank_operations

operations = [
    {"description": "Открытие вклада"},
    {"description": "Перевод с карты на карту"},
    {"description": "Открытие счета"},
]

categories = ["вклада", "перевод", "открытие"]
result = process_bank_operations(operations, categories)
# Результат: {'вклада': 1, 'перевод': 1, 'открытие': 2}
```

### 3. Функция `main()`
**Расположение:** `src/main.py`

Основная функция программы, которая реализует интерактивную работу с банковскими операциями.

## Функциональность программы

При запуске программы пользователю предлагается:

1. **Выбор источника данных:**
   - JSON-файл
   - CSV-файл
   - XLSX-файл

2. **Фильтрация по статусу:**
   - Программа попросит ввести статус операции
   - Доступные статусы: EXECUTED, CANCELED, PENDING
   - При вводе некорректного статуса программа вернёт пользователя к повторному вводу

3. **Опциональная сортировка по дате:**
   - Пользователь может выбрать сортировку по возрастанию или убыванию

4. **Фильтр по валюте:**
   - Вывод только рублевых транзакций (по желанию пользователя)

5. **Поиск по слову в описании:**
   - Пользователь может отфильтровать операции по определённому слову в описании

6. **Вывод результатов:**
   - Программа выводит отформатированный список операций
   - Если результат пуст, выводится соответствующее сообщение

## Запуск программы

```bash
# Запуск из командной строки Python
python -m src.main

# Или из скрипта Python
from src.main import main
main()
```

## Особенности реализации

- Использование `re` модуля для регулярных выражений в функции `process_bank_search()`
- Поддержка JSON, CSV и XLSX форматов (XLSX требует установки `openpyxl`)
- Обработка ошибок при загрузке файлов
- Маскирование номеров карт и счетов при выводе
- Форматирование дат в формат DD.MM.YYYY
- Case-insensitive поиск и фильтрация по статусам
