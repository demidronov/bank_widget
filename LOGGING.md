# Логирование в проекте

## Описание

В проекте реализована система логирования с использованием встроенной библиотеки Python `logging`. Логирование настроено для модулей `masks` и `utils`.

## Файлы логирования

Логи записываются в папку `logs` в корне проекта:
- `logs/masks.log` - логи модуля `masks`
- `logs/utils.log` - логи модуля `utils`

## Формат логов

Каждая запись лога содержит:
- **Метка времени** - дата и время события в формате `YYYY-MM-DD HH:MM:SS`
- **Имя модуля** - название модуля, из которого было произведено логирование
- **Уровень серьезности** - один из уровней: DEBUG, INFO, WARNING, ERROR
- **Сообщение** - описание события или ошибки

Пример строки лога:
```
2026-03-04 20:41:32 - src.masks - INFO - Started masking card number
```

## Описание уровней логирования

- **DEBUG** - детальная информация для диагностики
- **INFO** - информационные сообщения о нормальном ходе работы
- **WARNING** - предупреждения о потенциальных проблемах
- **ERROR** - сообщения об ошибках

## Логируемые события

### Модуль `masks`

- **INFO**: Начало маскирования номера карты/счета
- **DEBUG**: Успешное маскирование номера
- **WARNING**: Количество цифр меньше необходимого

### Модуль `utils`

- **INFO**: Начало загрузки транзакций и успешная загрузка
- **WARNING**: Файл не существует или пуст
- **ERROR**: Ошибки при парсинге JSON или чтении файла

## Поведение логов при запуске

Логи перезаписываются при каждом запуске приложения (используется режим файлового обработчика `'w'`). Это означает, что каждый новый запуск начинает с чистого лог-файла.

## Использование логирования в коде

Логирование уже настроено в модулях `masks` и `utils`. При добавлении новых модулей следуйте этому шаблону:

```python
from .logging_config import setup_logger

logger = setup_logger(__name__)

# Использование логирования
logger.debug("Детальная информация")
logger.info("Информационное сообщение")
logger.warning("Предупреждение")
logger.error("Сообщение об ошибке")
```

## Расположение файлов

```

├── src/

│   ├── masks.py             # Модуль с логированием
│   ├── utils.py             # Модуль с логированием
│   └── ...
├── logs/                    # Директория с логами
│   ├── masks.log
│   └── utils.log
└── ...
```

## Проверка логирования

Для проверки работы логирования используйте скрипт `test_logging_setup.py`:

```bash
python test_logging_setup.py
```

После выполнения проверьте содержимое файлов в папке `logs`.
